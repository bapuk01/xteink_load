# xteink_load

Простое Android-приложение: следит за выбранной папкой с книгами на телефоне и, когда появляется новая книга, отправляет её на читалку Xteink X4 с прошивкой CrossPoint по Wi-Fi.

## Скачать

**[Скачать xteink_load.apk](https://github.com/bapuk01/xteink_load/raw/main/xteink_load.apk)** — подписанная релизная сборка, ставится на Android 8.0+ (разрешите установку из неизвестных источников).

Использует встроенный веб-сервер CrossPoint (`POST /upload`, `GET /api/files`).

## Как пользоваться

1. На читалке: **Home → File Transfer → Join Network**, выбрать ту же Wi-Fi сеть, что и на телефоне (только 2.4 GHz). На экране появится адрес вида `http://192.168.1.102/`.
2. В приложении ввести этот адрес в поле «Адрес читалки».
3. «Папка на читалке» — по умолчанию `/Books`.
4. Нажать «Выбрать папку с книгами» и указать папку на телефоне.
5. «Сохранить настройки», затем «Синхронизировать сейчас».

После этого приложение само проверяет папку примерно раз в 15 минут и отправляет новые книги.

## Важно

- Автосинхронизация работает только пока на читалке открыт **File Transfer** (Join Network) и телефон в той же Wi-Fi сети. Если читалка выключена или не в этом режиме, приложение просто пропускает проверку и попробует позже.
- Адрес лучше брать с экрана читалки (IP). Имя `crosspoint.local` Android не всегда резолвит.
- Книги отслеживаются по имени и размеру. Если книга уже есть на читалке с таким же именем, она не отправляется повторно. Удалённые на читалке книги приложение заново не шлёт.
- Поддерживаемые форматы: `epub`, `txt`, `md`, `xtc`.
- Первый запуск отправит все книги из папки, которых ещё нет на читалке.
- Трафик не шифруется (HTTP), используйте только в домашней сети.

## Сборка

Проект рассчитан на Android Studio (Ladybug или новее), JDK 17, minSdk 26.

1. Открыть папку `D:\project\xtink` в Android Studio.
2. Дождаться Gradle sync. Если Studio жалуется на wrapper, выполнить в терминале `gradle wrapper` (нужен установленный Gradle) или дать Studio создать его.
3. Run на телефон или Build → Build APK(s).

## Структура

- `app/src/main/java/com/xtink/sync/MainActivity.kt`: экран настроек и ручная синхронизация
- `Syncer.kt`: логика — сравнивает папку телефона с уже отправленным и шлёт новое
- `ReaderClient.kt`: HTTP-клиент к читалке (список файлов, загрузка multipart)
- `SyncWorker.kt`, `SyncScheduler.kt`: фоновая проверка раз в 15 минут (WorkManager)
- `Prefs.kt`: настройки и список отправленных книг
